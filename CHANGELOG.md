# Changelog

All notable changes to this repository are documented here. The plugins in the kit keep their own changelogs.

## [Unreleased]

Front page only. The kit download is unchanged.

### Changed

- Front page laid out like the Sori page: a download button, a three-step picture, a full-width sample card and a setup illustration for each helper, and a how-it-works diagram.
- The Talent Alpha sample card is re-rendered with the plugin's own renderer and web search sources, the way the kit's helper finds news.

## [0.2.0] - 2026-11-11

### Added

- Front-page README with the kit download and three steps.
- Apache License 2.0, NOTICE, SECURITY.md, CONTRIBUTING.md and this changelog.
- Sample cards in `docs/`, made from fictional companies.

### Changed

- The scheduling recipes moved under `schedule/`.
- Recipes name the kit's plugin versions: Build Radar 2.0.0 and Talent Alpha 1.5.0.
- The Build Radar recipe installs from the kit instead of a repository link.
- Talent Alpha's schedule is labeled "Not yet proven" everywhere, with the same wording.
- Front page: the two files to upload are named, setup says to make and pick a folder, and "You need" lists the paid plan, web search and the website setting.
- The Talent Alpha sample card is captioned: it shows filed notices, while the kit's helper uses web search.
- The schedule page says it is optional and needs Python and the Code tab.
