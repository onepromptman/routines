# Changelog

All notable changes to this repository are documented here. The plugins in the kit keep their own changelogs.

## [0.2.0] - 2026-11-11

### Added

- Front-page README with the kit download and three steps.
- Apache License 2.0, NOTICE, SECURITY.md, CONTRIBUTING.md and this changelog.
- Sample cards in `docs/`, made from fictional companies.

### Changed

- The scheduling recipes moved under `schedule/`.
- Recipes name the kit's plugin versions: Build Radar 1.2.4 and Talent Alpha 1.5.0.
- The Build Radar recipe installs from the kit instead of a repository link.
- Talent Alpha's schedule is labeled "Not yet proven" everywhere, with the same wording.

## [0.1.0] - 2026-11-10

### Added

- Scheduled task recipes for Build Radar (tested once on 2026-11-09) and Talent Alpha (not yet proven).
- Tester section pointing to the kit on the Releases page.
