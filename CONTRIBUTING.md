# Contributing

Thanks for trying the kit. The most useful thing you can send is what confused you or where it stopped.

## Report something

Open an issue with:

- Which plugin (Build Radar or Talent Alpha) and which step from **Start here.html** or a recipe.
- What you typed, what Claude said, and what you expected.
- The plugin version. Claude reports it at the end of a run.

Please leave out anything personal: your profile file, your company's name if it matters to you, and any card that names a real company you would rather not post.

## Change something

- Recipes and the front page live here. Edit the Markdown and open a pull request.
- The plugins' code lives in their own repositories, linked from the README. Changes to how a plugin works go there, not here.
- Plain language, short sentences, no jargon without a one-clause explanation the first time.
- Line endings are LF. The repository's `.gitattributes` enforces that on commit.
