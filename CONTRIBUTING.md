# Contributing

Thanks for trying the kit. The most useful thing you can send is what confused you or where it stopped.

## Report something

Open an issue with:

- Which helper (Build Radar or Talent Alpha), app, and setup or run step.
- What you typed, what the app said, and what you expected.
- The kit or plugin version, if you have it.

Please leave out anything personal: your profile file, your company's name if it matters to you, and any card that names a real company you would rather not post.

## Change something

- The recipes, front page, and Dot installer live here.
- Talent Alpha's code lives in its own repository, linked from the README. Build Radar's code ships inside the kit. For a change to how either plugin works, open an issue here first.
- Plain language, short sentences, no jargon without a one-clause explanation the first time.
- Line endings are LF. The repository's `.gitattributes` enforces that on commit.
